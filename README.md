# 阿拉伯语每日单词打卡 · عربي كل يوم

一个**单文件、离线可用**的阿拉伯语背单词网页工具，内置《词汇表_乱序.doc》的 **932 个词条**，
手机 / 电脑打开即用，学习记录保存在浏览器本地（localStorage），不联网、不上传任何数据。

> 在线体验：`https://<你的用户名>.github.io/<仓库名>/`（见下方「部署到 GitHub Pages」）

---

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 👤 **进度池** | 多人 / 多份进度各存一个「池子」：进度、习惯、打卡、单词本全独立，顶部一键切换，可新建/改名/复制/删除/导入导出 |
| 📖 **背诵区 · 阿→中** | 认读：看阿语想中文，点「显示释义」自评 |
| 📖 **背诵区 · 中→阿** | 回想：看中文想阿语，点「显示释义」看标准答案 |
| 🎚 **分配比例** | 今天的词按比例切给两个子分区（默认各一半，总量不变）；也可切成「中→阿 跟练阿→中」用同一批词练两遍 |
| ✍️ **默写区** | 打字模式：输入中文释义或**阿拉伯语**（自带 36 键阿语屏幕键盘，无需安装阿语输入法） |
| 🔗 **先背后默写** | 默写区默认**同步背诵区**：三个分区今天背过哪些词就默写哪些词，背完提示「去默写」 |
| 🔁 **上一个 / 下一个** | 卡片下方可自由翻页：跳回上一张复习、跳到下一张或先跳过稍后再背；末张也有明确反馈，不会「卡住」 |
| 🧠 **记忆曲线** | 记住了按 1/2/3/7/14/30/60 天安排复习；没记住当天最多再问 3 次，并优先排进明天的任务 |
| 🎲 **随机抽查** | 每天按比例从**已学过的词**里随机抽一部分复习（名额内优先满足到期的词） |
| ✅ **打卡** | 三个分区都完成即可打卡，含连续打卡、最长连续、28 天日历、历史记录、默写一次写对率 |
| 🔤 **词头 / 补充形式** | 自动把 `جـ`（复数）、`م`（阴性）、动词变位拆成小字「补充形式」，大字只显示词头 |
| 🔊 **朗读** | 点击单词用系统语音朗读（需系统装有阿拉伯语语音包） |
| 💾 **导入 / 导出** | 支持粘贴 `单词 : 释义` 批量导入；可导出整份 JSON 备份与恢复（按池导出/导入） |

## 🚀 使用

1. 下载 `daily-arabic.html`，**双击**用浏览器打开（或访问部署好的在线地址）。
2. 首次打开先给自己的**进度池**起个名字（多人共用一台设备时，一人一个池子）。
3. 「📖 背诵区 · 阿→中」先认读今天的新词 → 切到「📖 背诵区 · 中→阿」反过来想一遍 → 最后到「✍️ 默写区」默写同一批词。
4. 顶部折叠面板可调每天背多少、两个方向怎么分、默写要不要跟着背诵区走。
5. 全部完成后点「✅ 打卡」。

## 🌐 部署到 GitHub Pages

**方式一：网页上传（不用命令行）**

1. 新建仓库 → `Add file` → `Upload files`
2. 把 `index.html`、`daily-arabic.html`（可选 `README.md`、`Explain.md`、`input.txt`）拖进去 → `Commit changes`
3. 仓库 `Settings` → `Pages` → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → `Save`
4. 等 1 分钟左右，访问 `https://<用户名>.github.io/<仓库名>/` 即可

**方式二：命令行**

```bash
git init
git add index.html daily-arabic.html README.md Explain.md input.txt
git commit -m "阿拉伯语每日单词打卡工具"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

> ⚠️ **注意**：学习数据存在浏览器的 localStorage 里，按「来源」隔离。
> 从本地文件（`file://`）打开时的记录**不会**自动出现在 GitHub Pages 网址上。
> 迁移方法：设置 →「导出当前池」复制 JSON → 在线页面设置页 → 「粘贴导入为新池」。

## 📚 词表

- 内置 932 个词条来自《词汇表_乱序.doc》（含 120 个原文标 `*` 的补充词），已修正 26 处原文笔误。
- 想换成自己的词表：在「单词本」里粘贴 `单词 : 释义` 即可；或修改 HTML 里的 `const BUILTIN_WORDS`。
- `input.txt` 是同一份词表的纯文本版，便于查看与编辑。
- 详细用法见 `Explain.md`。
